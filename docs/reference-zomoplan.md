# 参考产品能力清单：朝暮计划（zomoplan.com）

来源：2026-11-05 用浏览器实测 `https://www.zomoplan.com/web/list` 等页面 DOM，并从其前端包
`/web/static/js/app.7724557f.js`（684KB）中提取全部 UI 文案与 store 字段名。以下条目均有一手证据，
标注「移动端」的项是包内出现但 Web 端未提供的能力。

## 0. 产品结构

四个一级模块，Web 端路由 `/web/list`、`/web/view`、`/web/habit`、`/web/memo`：

| 模块 | 内容 |
|---|---|
| 清单 | 待办事项，三种分组方式：按日期 / 按分类 / 按四象限 |
| 视图 | 日历视图：日视图 / 周视图 / 月视图 + 自定义视图 |
| 习惯 | 习惯打卡，按「情境」分段（晨间/午间/晚间/全天） |
| 备忘录 | 富文本笔记，文件夹 + 回收站 |

数据表（从其 store 字段名 `listModules.tbListClock` 等推得）：
`tbListInfo` 清单本、`tbListClock` 事项、`tbListChild` 子任务、`tbListClassify` 分类、
`tbListLabel` 标签、`tbListRemind` 提醒、`tbHabitInfo` 习惯、`tbHabitClock` 打卡记录、
`tbHabitMark` 打卡日志、`tbHabitUnit` 习惯单位、`tbHabitClassify` 习惯分类。

同步：`/zhaoMuPlan/syncData/list`、`/syncData/habit`、`/syncData/memo` 三个域各自拉取；
界面上有「数据不同步？点此刷新」手动兜底，加载态文案区分「未拉取线上清单 / 已拉取线上清单」。

## 1. 清单（事项）

### 1.1 事项字段
标题、备注、图片附件（会员每条最多 5 张）、分类（图标+颜色）、优先级＝四象限、标签（最多 10 个）、
日期、时间、提醒、重复、子任务、打卡状态。

### 1.2 分组桶（按日期视图）
`逾期` / `未打卡`（今天应完成）/ `待办`（未来或无日期）/ `已打卡`。
- 组标题带计数，可折叠，可拖动排序。
- 逾期组顶部有「顺延到今天」批量操作；单条也可顺延，确认文案「顺延后日期将更改至今天」。
- 已打卡项显示「打卡时间：10月08日 17:42」，可隐藏（设置项「显示已打卡清单」）。
- 逾期项显示相对量「逾期73天」。

### 1.3 日期与时间
- 清单类型：**单日 / 跨天 / 自选多日**（免费用户跨天清单数量有限制，会员不限）。
- 时间形态：**全天 / 时间点 / 时间段**（如 `11月5日 全天`、`9月15日 15:00-16:00`）。
- 日期选择器带农历（廿七、廿八）、节气（立冬）、节日（元旦/情人节/妇女节/劳动节/儿童节/建军节/教师节/国庆节/平安夜/圣诞节/母亲节/父亲节/北方小年/南方小年）、调休标记（**班 / 休**）。

### 1.4 提醒
预设：`准时`、`提前5分钟`、`提前30分钟`、`提前1小时`、`当天(09:00)`、`当天(10:00)`、
`提前1天(09:00)`、`提前7天(09:00)`、`无提醒`，以及**自定义提醒时间**（按 天/小时/分钟 偏移的滚动选择器）。
免费用户提醒条数受限，会员可「多个提醒」（一条事项挂多个提醒时间点）。

### 1.5 重复（核心复杂点）
预设选项（实测顺序）：
`仅一次` / `每天` / `每周一至周五` / `法定工作日(不包含法定节日、假日)` / `每周(周一)` /
`每月(24日)` / `每年(08月24日)` / `艾宾浩斯记忆法` / `自定义重复`。

自定义重复维度：
- 单位：`天重复` / `周的周X` / `个月的X号`（支持**最后一天**）/ `年的X月X日`。
- `每隔N天`、`自选周期`（勾选周几集合）、`自选多日`。
- **跨天智能重复**：跨天清单只在周期命中日生成当天分段。
- **智能跳过法定节假日**：重复命中节假日时跳过。
- 结束条件：`永不结束` / `按日期结束`（结束日期）/ `按次数结束`（重复 N 次结束）。
- 修改/删除带重复的事项时，作用域三选一：`仅当天清单` / `当日及未来清单` / `全部清单`。
- 艾宾浩斯记忆法：按遗忘曲线间隔（1/2/4/7/15 天一类序列）自动生成复习事项。

### 1.6 子任务
`添加子任务，按回车快速保存`；子任务有独立标题、备注、提醒、开始日期、分类、置顶、优先级；
父项标题右侧显示完成进度 `0/4`，可折叠展开；有「设置进度」。

### 1.7 分类与标签
- 分类管理：名称、图标（内置图标集 + 自定义单字）、颜色；可拖动排序；删除时可选
  `删除分类并清空分类下清单` 或 `保留清单移动至 全部（无分类）`；可「显示无清单分类」。
- 标签：搜索或创建，编辑名称，单条事项最多 10 个标签。
- 四象限：`重要且紧急` / `重要不紧急` / `不重要但紧急` / `不重要不紧急`（新事项默认优先级 4）。

### 1.8 详情页交互
点击事项在列表内联展开详情（非弹窗）：顶部＝关闭、分类、四象限、更多操作；
正文＝标题、日期、时间、提醒、重复、标签、备注+图片、子任务列表。所有字段点后即改，自动保存。

## 2. 视图（日历）
日/周/月三种视图，月视图按周分行，每格显示事项标题，超出显示「还有N个任务」；
顶部有「回到本月/今天」、上/下月切换、新建清单入口。
自定义视图（会员）：**自定义视图内容**（按清单详情页面设置 / 按清单分类 / 按优先级）、
**自定义视图颜色**（设置固定颜色 / 跟随习惯图标颜色）。

## 3. 习惯
### 3.1 创建
第一步选图标：内置图标集按类分组（常用/健身/美妆/美食/坚果/旅行），或选「文」输入单字作为图标，
再选图标颜色；第二步命名。

### 3.2 习惯属性
- **打卡方式**：`每天一次` / `每天多次`。
- **习惯单位**：内置（个/步/米/公里/页/杯）或新建单位（最多两个字符）；
  量化习惯有 `每日打卡总量` 与 `每次打卡完成量`，列表里显示 `0/1`、`0/4`。
- **频率**：`固定`（勾选周几 / 每月几日）、`按周`、`按月`、`每隔N天`。
- **打卡方式开关**：`自动打卡`（到点自动记）/ `手动打卡`。
- **情境**：`晨间` / `午间` / `晚间` / `全天`，可新建与排序；删除情境后其下习惯移动到「全天」。
- **开始日期**：日历上标「开始」。
- **补打卡范围**：`habitMaxToPrev` 控制最早可回溯到哪一天。

### 3.3 打卡与统计
- 习惯行右侧是横向日期切片（月内 21…4 之类），单元格状态：未打卡 / 已打卡 / 未来不可点；
  多次打卡用 canvas 画部分完成环。
- 点击某天单元格 = 打开打卡标记模块（`openMarkModule`），可打卡/取消打卡/补打卡。
- 详情面板：**月打卡进度**（百分比 + `计划打卡`/`实际打卡`/`错过打卡`）、
  **打卡总进度**（`开始日期`/`距今日期`/`打卡总天数`/`最长连续天数`）、
  **打卡日志**（按日期分组，每条含时间、可编辑心得文本、配图）。
- 列表页顶部按情境分段（`晨间 1` / `午间` / `晚间 1`），显示「累计打卡N天」。
- 设置：显示已打卡习惯、情境管理、习惯分类。

## 4. 备忘录
左侧文件夹（含「全部」「回收站」），排序方式（按创建时间/按修改时间），搜索（回车触发），
新建/删除进回收站、回收站可恢复或永久删除；正文富文本：多种字体（默认/仿宋/楷体/手札体/娃娃体/雅痞）、
背景选择、附件（≤50M，图片单张 ≤10M）、云存储容量上限提示。

## 5. 账号与商业化（仅作对照，不复刻）
手机号验证码 / 微信 / QQ / Apple 登录；账号绑定与解绑；注销只能在移动端；
会员特权＝多个提醒、上传多张图片、多个习惯、跨天清单不限、月视图个性化；邀请码。
移动端另有 **番茄钟**、日记、生日提醒（Web 端未提供）。

## 6. 本项目第一版边界（已确认）
做：**清单 + 习惯** 两个模块，本地优先，单人多设备，同步通道可插拔且先落地飞书。
不做（暂缓）：日历视图、备忘录、番茄钟、账号体系、会员付费、图片云存储（改本地文件）。
后续里程碑再议：视图模块、iOS 打包（需要 macOS + Xcode 环境）。
